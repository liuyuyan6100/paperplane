# M4.2 封面与正文配图安装验收

候选应用`0.4.0-m4.2.1`，安装包`PaperPlaneStudioPreview-Setup-0.4.0.5.exe`。M4.1已验收；M4.2首包已安装体验并反馈问题，本包修正后待复验。

先保存当前文字，再运行普通安装向导。点击安装后覆盖原“纸飞机架构验证版”，原文章、修订、任务、画像、图片、模型设置和关闭习惯保留；无需先卸载。完成后从桌面/开始菜单打开，展开底部信息核对版本。正式版与正式数据仍独立。

操作正文集中在[封面与正文配图使用指南](../../feature-guides/m4.2-images.md)。按M4.2-01至13验证；优先复验04的点击直接生成、05/06的封面到正文插图入口、11的整篇图文预览、12/13的永久删除与空间清理。实际结果记录到[本轮反馈与复验](../../feature-guides/records/m4.2.1-feedback-2026-10-20.md)。生成会使用现有图片服务并可能计费，初始计划与浏览历史不调用模型。永久删除使用不再需要的测试文章。

候选包、自动回归、失败修正及数据回退边界见[实施记录](04-images-implementation.md)。普通向导打开、实际安装与用户确认分别登记，不因自动测试成功而提前推进后续迁移单元。
