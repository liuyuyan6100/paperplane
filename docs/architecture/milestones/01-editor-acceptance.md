# M1 文章编辑安装验收

状态：M1 候选 `0.2.0-m1.1` 已实现、回归并打包，待用户安装与验收。安装向导由使用者确认，不能将候选交付视为验收完成。

## 这一轮学会什么

在架构验证版中建立文章，理解“编辑中的内容”和“已经保存的版本”的区别，并体验预览、保存、重新打开及冲突处理。侧边 AI 的新组件和任务中心分别留到后续阶段。

## 交付前由开发方验证

- [x] 前后端构建通过，运行依赖和 npm 版本固定，静态资源随 Windows 包交付。
- [x] 独立程序名、AppId、数据目录和实例锁；原正式程序与数据未作改动，实际并存安装待用户验证。
- [x] 新文章列表/编辑/预览/保存使用新框架，兼容入口连接同一验证库。
- [x] 旧功能回归、接口安全边界、浏览器竞争条件及成品启动检查通过。
- [x] 版本、源码分支、安装包 SHA256、测试结果与已知限制见 [实施交付记录](01-editor-implementation.md)。

## 用户安装后逐项操作

| 操作 | 预期结果 | 用户结果 |
| --- | --- | --- |
| 安装并打开验证版 | 标题显示验证版，数据目录独立，稳定版原文章没有变化 | 待验证 |
| 新建“编辑验收样稿” | 可填写标题、摘要、作者、标签、正文等原有字段 | 待验证 |
| 输入中文、列表、链接、Markdown 和媒体引用 | 编辑与预览正确；保存后重开仍保留内容 | 待验证 |
| 修改正文但不保存，尝试切换文章 | 明确提醒，取消切换后继续保留输入 | 待验证 |
| 在同一文章打开两个编辑页面，先后保存不同修改 | 后保存的旧版本被拒绝覆盖，本地文字仍可保留处理 | 待验证 |
| 保存请求尚未结束时继续输入 | 新输入不会被保存响应或后台刷新清掉 | 待验证 |
| 使用兼容入口打开未迁移功能 | 能返回原有功能，连接验证库，不打开正式库 | 待验证 |
| 退出后重新打开 | 已保存文章保持，版本信息一致 | 待验证 |

不要求使用者手工模拟所有网络竞争条件；开发方先用确定性测试验证，验收包提供合成示例与简明步骤。真实文章与密钥不需要放进问题反馈。

## 结果与反馈

候选包：`PaperPlaneStudioPreview-M1-Setup-0.2.0.1.exe`。安装状态：待用户安装。用户确认：尚无。发现的问题在此逐项登记，关联复现步骤、修复提交与复验结果。只有用户明确确认通过，才将 M1 标为验收完成并推进 M2。

先打开桌面“纸飞机架构验证版 M1”，点“创建验收样稿”，修改一段正文、预览、保存，再从左侧重开核对。需要双窗口时展开页面底部“验证版信息与本轮范围”，点击另开浏览器链接。旧功能通过左下角“打开原工作台”使用，右下角可返回新编辑器。
