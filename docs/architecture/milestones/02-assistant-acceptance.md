# M2 侧边 AI 安装验收

候选：`0.2.0-m2.1`；M1 已由用户确认通过。本轮交付 M2，用户安装体验尚待确认，M3 未开始。

安装前保存 M1 中尚未保存的文字，再运行 `PaperPlaneStudioPreview-Setup-0.2.0.2.exe` 的普通安装向导。点击安装后，程序自动退出原验证版并替换程序文件；原 M1 文章和设置保留。无需先手动卸载 M1，同一 AppId 原位升级，桌面和应用列表固定使用“纸飞机架构验证版”，移除 M1 旧快捷方式。原正式版纸飞机保持独立。

首次正常打开 M2，自动读取原纸飞机本机加密配置，补齐模型、按功能模型、生图和平台配置，保留验证版已填设置。无需重新逐项填写；配置不持续双向同步。平台账号记忆会复用，但浏览器登录状态仍需实际核验，不能把账号名称当作已登录。正式文章不会自动复制到验证库。

| 步骤 | 预期结果 | 用户结果 |
| --- | --- | --- |
| 升级后打开“纸飞机架构验证版” | M1 文章仍在，页面显示 M2，桌面不再多出一个 M2 应用 | 待确认 |
| 打开 M1 测试稿，查看侧栏模型提示 | 显示已有讨论、修改模型；不要求重新填写接口和密钥 | 待确认 |
| 选择“仅讨论”，询问一处表达问题 | 有回复，正文保持原样，切换文章后回来仍有记录 | 待确认 |
| 选择“修改文章”，要求简化一段 | 出现可展开的差异和完整建议，原稿仍保持 | 待确认 |
| 点击“填入编辑区”，再点“撤销填入” | 先成为未保存编辑，再能撤回；后续手动编辑后不再允许旧撤销覆盖 | 待确认 |
| 在含中文、emoji 的正文选中一段，再点“使用选中片段” | 明确显示范围，只修改选中段落；修改选区后提示重新选择 | 待确认 |
| 点“继续调整”，写一条新的要求 | 基于当前编辑稿承接上次建议；不会回滚手动修改 | 待确认 |
| 填入建议后保存、退出并重开 | 正文和对话保留；未点保存前不会自动保存或送稿 | 待确认 |

遇到失败时，本次记录显示失败或中断，可手动重试；网络回执不明时不自动重复派发。AI 生成期间仍可编辑正文，若稿件已变化，旧建议保留供参考，不能直接覆盖当前文字。

验收结果以用户反馈更新本单；开发方回归、真实模型与成品验证见 [实施记录](02-assistant-implementation.md)。
