# M2 侧边 AI 安装验收

当前候选：`0.2.0-m2.5`。用户继续反馈历史建议已取用、稿件变化后不清楚如何修改。本次补齐历史建议承接当前稿的明确入口，M3 未开始。

安装前保存当前版本中尚未保存的文字，再运行 `PaperPlaneStudioPreview-Setup-0.2.0.6.exe` 的普通安装向导。点击安装后，程序自动退出原验证版并替换程序文件；当前验证库文章、对话和设置保留。无需先手动卸载 M1，同一 AppId 原位升级，桌面和应用列表固定使用“纸飞机架构验证版”，移除 M1 旧快捷方式。原正式版纸飞机保持独立。

首次正常打开 M2，自动读取原纸飞机本机加密配置，补齐模型、按功能模型、生图和平台配置，保留验证版已填设置。无需重新逐项填写；配置不持续双向同步。平台账号记忆会复用，但浏览器登录状态仍需实际核验，不能把账号名称当作已登录。M2.2 还会补齐原纸飞机已保存的账号画像、视觉风格和仅供风格使用的参考图，已有同名或同 ID 画像不覆盖。正式文章与任务不会自动复制到验证库。

## M2.3 设置页模型目录复验

打开“模型与生图设置”，直接展开默认文字、讨论、修改模型的下拉框，无需清空已有名称，应能看到完整目录。选择并保存后重新打开，所选值保持；讨论/修改、封面/正文插图可选“跟随默认”。需要填写目录未列出的模型时，点对应字段的“手动填写”；再点“从目录选择”仍保留所填值。文字和生图分别读取各自接口目录，若图片接口实际仅返回一个模型，则只显示这一个已识别模型，不凭空添加。


## M2.4 伸缩侧栏与对比阅读复验

1. 拖动文章与 AI 之间的分隔线，侧栏能调宽、调窄；双击恢复默认宽度。分隔线也支持左右方向键。缩小窗口后仍能操作保存和发送。
2. 在 AI 要求框写一段但先不发送，点击顶部“收起 AI”，文章区展开；再点“展开 AI”，输入和对话保留。当前服务会话内刷新页面可保留宽度偏好；未发送要求仍仅在当前页面内保留。
3. 生成修改建议，点“查看修改对比”。宽窗口左右显示“修改前 / 建议稿”，标题、段落、列表和代码按 Markdown 排版；橙色标出原稿的删改块，绿色标出建议的新增或改写块。可取消“突出改动”专心阅读。高亮按内容块，不是逐字红线。
4. 关闭对比或按 Escape，文章应没有被改动或自动保存；继续调整仍沿用原流程。确认后点弹窗“填入编辑区”，可撤销，仍需自行保存。
5. 手动修改文章后查看旧建议，左边仍是发送当时的快照，显示文章已变化，不能直接填入覆盖新内容。
6. 窄窗口中两份稿上下排列，正文区域滚动，关闭和填入按钮保持可用。

以上为本轮验收步骤，用户结果均待确认；自动验证见实施记录。


## M2.5 历史建议怎样继续修改

历史记录无需删除或重新填入。它保留当时的原稿与建议；当前文章已有变化时，直接覆盖旧建议会丢掉后续修改。

1. 找到旧建议，点击“基于当前稿继续修改”，或在旧对比弹窗底部点同名按钮。回到要求框后会自动定位光标，已有未发送要求保留。
2. 输入新的要求，例如“基于当前正文，把第二段再写得简洁一些”，按 Ctrl+Enter。默认使用当前编辑稿全文，旧选区已清除；只想改一段时，重新选中正文再点“使用选中片段”。不会自动重发旧要求。
3. 新建议生成后查看对比，确认后填入、保存。新请求以当前未保存编辑为底稿，引用旧建议供承接，不把旧正文恢复回来。

旧记录中不再显示失效的填入按钮。以上步骤用户体验待确认，历史对话和原文章继续保留。
