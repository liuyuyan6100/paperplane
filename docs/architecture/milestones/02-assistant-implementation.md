## 实现范围

前端 `features/assistant` 独立管理对话查询、讨论/修改模式、明确启用的选区、差异、建议、继续调整、失败重试；输入区固定，对话独立滚动。当前编辑区的未保存标题和正文直接作为请求快照；更换画像后须先保存，避免新旧画像混用。Unicode 选区从浏览器 UTF-16 转换成后端代码点，选区之前的改动会调整偏移，重叠改动令选区失效并保留输入。

编辑 reducer 负责建议填入与撤销，网络回复不能直接改 DOM。填入前后都检查文章会话、编辑序号、保存状态与原内容；手动编辑或切换文章后的迟到响应被忽略。填入仅改变本地编辑稿，须自行保存；不创建创作任务、不送稿。撤销只作用于最近一次填入，后续手写后失效。

后端 `AssistantService` 通过窄接口委托 `LegacyAssistant`，复用原 `editor_assistant` 的对话表、模型路由、快照、重试和版本检查；FastAPI 负责类型与安全边界。采用/重试还核对记录所属文章。前端请求 ID 在网络失败后保留，同内容再次提交可以去重；不自动重发模型请求。

普通桌面默认启动才执行一次配置补齐：读取正式本机 DPAPI 配置，通过原 Config 写入验证版加密文件；已有非空字段不覆盖。复制已保存的模型/生图/公众号/DEV 配置、未独立改动的渠道设置和账号记忆，不复制正式文章、任务或模型自测成功回执。浏览器用户目录保持隔离，账号记忆不表示登录已验证。导入回执只记录字段数量与状态，不记录密钥。`--serve`、`--smoke-test` 与自定义隔离数据目录不会读取正式配置。

固定应用名“纸飞机架构验证版”，保持 M1 的 AppId、EXE、安装和数据路径。无需单独执行 M1 卸载器；安装向导点击安装后，复用已有升级助手，只终止完整可执行路径匹配的旧验证版及其子进程，再替换已核验的 EXE/运行目录；删除精确命名的 M1 快捷方式。安装不删除用户数据。原正式程序使用不同身份，不被本次升级助手关闭。

## 复现与边界

```powershell
npm.cmd ci --prefix frontend
npm.cmd run lint --prefix frontend
npm.cmd test --prefix frontend
npm.cmd run build --prefix frontend
.\.venv\Scripts\python.exe -m pytest -q
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/build_preview.ps1
```

`tools/verify_preview_package.py` 核对冻结代码/资源并实际启动、保存、重启验证；`tools/verify_preview_upgrade.ps1` 使用两个隔离的旧版成品目录，验证只结束目标目录、另一实例和已有应用存活、数据保留、拒绝数据目录。真实模型检查工具 `python -m tools.verify_preview_model` 需要显式提供全新隔离目录，不属于普通测试或自动启动动作。

本轮只迁移文章旁的文字协作；原工作台仍承载其他工作项对话、画像经验审核、素材、图稿和发布流程。M3 的统一任务视图、SQLAlchemy/Alembic 迁移尚未实施。按 [M2 验收单](02-assistant-acceptance.md) 完成用户体验确认后再进入下一阶段。
