# M4.4 图文检查与公众号草稿衔接

2026-10-23，作者：灵魂工程师。用户确认M4.3.3本轮验收通过，并授权开始窄范围草稿衔接。应用`0.4.0-m4.4-drafts`，安装包`0.4.0.13`。本轮用户验收尚未完成。

## 范围与边界

新增独立DraftPanel，编辑器、图文预览和视觉入门均能打开；不要求再进入旧页面查看检查。问题优先展示，提供文章信息/配图/公众号设置/任务中心入口。查看只读；明确启动后复用原格式整理、缺项等待、AI建议审阅、保存自动复查与草稿执行器。

API/application/domain/legacy adapter四层边界：GET文章draft投影，POST start/cancel/prepare/confirm。复用ArticleFlow及DraftPreparation，抽出同一只读check方法供显示和执行检查门共用。严格版本、文章归属和会话令牌检查。投影只取任务id/status/version/error/note/external_id/updated_at，不返回含渠道凭据的snapshot。原任务与已清理任务的去重语义保留。

前端复用SaveRequest/reducer，命令引起的文章版本变化仅按当前会话响应；晚到响应不能覆盖后续编辑。轮询只更新检查面板，不自动载入文章。版本不同须主动载入最新并沿用离开保护。补齐任务纳入桌面退出运行任务判断；重启继续沿现有中断恢复规则。

没有新增表、调度器、实际公开发表、自动更新已有微信草稿、公众号配置迁移、多平台工作。检查采用现有规则，不承诺检测所有语义错误或远端链接可用性。实际送稿沿平台权限与网络条件，结果未知先核对。
