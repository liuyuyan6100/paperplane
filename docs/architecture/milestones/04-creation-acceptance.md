# M4.1 素材到正文采用安装验收

版本 `0.4.0-m4.1`，安装版本 `0.4.0.1`。M1–M3已用户验收，本单用于M4首个创作链单元；用户安装与体验待确认，其他M4功能未全部迁移。

先保存当前编辑，运行 `PaperPlaneStudioPreview-Setup-0.4.0.1.exe` 普通安装向导。点击安装后才退出旧验证版并覆盖程序；同名、同AppId、同验证库，现有文章、修订、对话、画像、素材和设置保留。无需先卸载或重新逐项配置。完成后从桌面/开始菜单打开“纸飞机架构验证版”，核对底部版本。原正式版与其数据保持独立。

不要求为验收强杀进程、破坏配置或真实送稿。危险竞争分支由隔离故障回归覆盖，不能据此声称各平台、图片或视频已实测。本轮不创建真实送稿、公开发表或迁移正式数据。
