# M4.1 素材到正文采用安装验收

版本 `0.4.0-m4.1`，安装版本 `0.4.0.1`。M1–M3已用户验收，本单用于M4首个创作链单元；用户安装与体验待确认，其他M4功能未全部迁移。

先保存当前编辑，运行 `PaperPlaneStudioPreview-Setup-0.4.0.1.exe` 普通安装向导。点击安装后才退出旧验证版并覆盖程序；同名、同AppId、同验证库，现有文章、修订、对话、画像、素材和设置保留。无需先卸载或重新逐项配置。完成后从桌面/开始菜单打开“纸飞机架构验证版”，核对底部版本。原正式版与其数据保持独立。

## 一次完整创作

1. 新建测试文章，填写标题和简单想法，选择需要的画像，点“保存文章”。顶部点“素材与创作”。
2. 勾选已有文章或笔记作为素材；也可展开“新增文字素材 / 导入文件”，粘贴文字或导入UTF-8的 `.md`、`.txt`、`.csv`，点“保存素材并选用”。共享资料库文字可从同一窗口读取并导入。最多6份，只引用明确选择的素材，原文件和共享资料不改动。
3. 填写要求，点“生成提纲”。查看、修改标题和提纲，可先“保存提纲”；关闭再打开窗口仍可继续。本阶段原文章正文应保持不变。只有点“确认提纲并生成正文”才开始正文生成。
4. 等待正文进入待审，核对提醒、来源与全文。可以“修改待审稿”，再“保存待审稿修改”；这时原文章仍不改变。对照当前文章与待审稿后，点“确认采用并保存文章”，结果保存为文章新版本，原修订保留。
5. 返回文章、完全退出再从桌面重开。确认采用的正文仍在，“素材与创作”的历史任务与M3任务中心记录仍能查看，原侧边AI与“打开原工作台”入口正常。

生成提纲和正文会分别调用已有模型，查看、编辑和采用本身不调用模型或送稿。

## 继续调整与冲突

| 情形 | 应看到的结果 |
| --- | --- |
| 正文不满意，沿用结构 | 点“沿用已确认提纲重写”，相同输入沿用确认；新正文仍为待审，不自动采用 |
| 想换素材或要求 | 点“调整素材和要求”，更新后创建新任务，原提纲保留并要求重新确认，旧任务和结果保留 |
| 生成中修改并保存原稿 | 原任务继续按旧输入完成；采用时先对照当前稿和候选，可保留当前稿、明确采用候选或手动合并；旧修订不删除 |
| 原稿仍有未保存文字 | 先返回文章保存，再回来核对采用；不会被后台刷新或迟到采用响应覆盖 |
| 待审稿或提纲被另一页面修改 | 旧版本保存/采用被拒绝，本地编辑保留，可明确读取新版本后核对 |
| 生成失败或完全退出导致中断 | 输入和已完成记录保留，从M3任务中心按原ID手动恢复；重开不自动付费重跑 |
| 暂时不采用 | 点“保留当前稿，暂不采用”，返回文章，待审稿和任务继续保留 |

不要求为验收强杀进程、破坏配置或真实送稿。危险竞争分支由隔离故障回归覆盖，不能据此声称各平台、图片或视频已实测。本轮不创建真实送稿、公开发表或迁移正式数据。
