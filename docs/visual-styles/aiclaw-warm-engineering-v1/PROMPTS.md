# 可复制的生图提示词

使用前，把 `reference-cover.png` 作为风格参考图实际附给生图工具，并填写主题、文字与画幅。工具不支持图片输入时，可用下列文字生成近似版本，但不能声称已使用参考图。

## 共用风格段

参考附图的视觉风格，为 Aiclaw 创作一幅温暖工程手绘插画。只继承纸感、画法、配色、自然暖光和视觉层级，不复制原图标题、人物外貌或具体道具。暖米白纸张背景，细腻深色墨线，柔和水彩和彩铅式质感，深海军蓝构成主要视觉骨架，低饱和木色与青绿，少量橙色强调。画面安静、专注，有真实实践的生活气息，像技术杂志的手绘插页。主体根据本次内容选择，留白克制，避免科幻机器人、霓虹、光滑 3D、幼儿卡通和堆砌装饰。只绘制明确给出的文案，不自行添加屏幕字、标语、书脊文字或数据。清晰度和事实准确性优先。

## 封面任务段

类型：文章封面。主题：{主题}。画幅：{比例或像素}。主标题逐字为“{标题}”，副标题逐字为“{副标题或无}”。用一个与主题有关的动作场景表达含义：{场景}。标题为清晰的深海军蓝中文无衬线粗体，手机缩略图仍能阅读。标题与场景有明确主次，保持安全边距；可小号署名 Aiclaw。为当前画幅重新构图。

## 正文插画任务段

类型：正文插画。要解释的唯一观点：{观点}。画幅：{比例}。用{场景或隐喻}表达，使用同一纸感、墨线、水彩和配色。{无大标题／准确标题}。图中文字只允许“{标签清单；无需文字则填无}”。不把插画画成第二张文章封面，不虚构运行截图或实验结果。

## 解释图任务段

类型：手绘解释图。画幅：{比例}。本图只说明{一个问题}。必须保留以下节点、顺序和关系：{逐项列出经过核对的节点与关系}。用手绘笔记卡、小设备或简化图形表示节点；箭头方向清楚、无歧义。每个标签逐字为{标签清单}，不得改字或添加节点。采用共用风格段的纸感和色板，减少场景装饰，优先保证文字与连线清晰。

## 跨平台知识图卡任务段

类型：同系列图卡，第 {序号}/{总数} 页。画幅：{比例}。本页独立讲清{观点}，正文要点仅包含{核实过的要点}。保持本系列纸感、笔触、色板与标题层级，但按本页信息重排布局。不要机械裁切原封面，不新增事实、统计或效果承诺。{署名要求}。

## 交给其他创作平台的整段指令

请将随附 STYLE.md 与 reference-cover.png 保存为当前 Aiclaw 画像的视觉基准，风格 ID 为 aiclaw-warm-engineering。为这份画像制作封面、正文插画或图卡时先读取规范并查看参考图；能传参考图的生图工具，必须实际传入图片。按主题改变场景，按平台改变画幅，保持纸感、笔触、色板与氛围。不要影响其他账号画像。请分别说明规范已保存、任务是否读取、图片是否传给生图工具、结果是否核验；没有完成的部分不要报告为已经生效。
