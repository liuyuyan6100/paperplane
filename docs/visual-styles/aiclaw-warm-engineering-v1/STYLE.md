# Aiclaw 温暖工程手绘

风格 ID：`aiclaw-warm-engineering` · 版本：1.0.0 · 用户确认日期：2026-09-27。

适用范围：Aiclaw 的公众号、博客及其他平台内容，包含封面、正文场景插画、解释图和知识图卡。不同账号或其他画像不自动继承。用户当次要求可以覆盖本规范。

## 参考图与继承方式

`reference-cover.png` 是用户明确喜欢的原始封面，作为视觉基准。开始创作前同时读取本文件并查看原图；生成工具支持参考图时，把原图作为真实图片输入，不能只在提示词里写文件名。这是风格参考，不是要复刻其标题、男人外貌、电脑、桌面或窗外景色。

继承的核心是：**米白纸感 + 深海军蓝视觉骨架 + 柔和暖光 + 细墨线与水彩/彩铅质感 + 具体的实践场景 + 克制留白**。风格要温暖、认真、有人的生活气息，像技术创作者的手绘杂志插页。

## 视觉规范

- 背景：暖米白、浅纸纹，主体周围有呼吸感；纸纹不能妨碍阅读。
- 画法：细腻但不僵硬的墨线，柔和水彩与彩铅式明暗，适度细节和自然材质，保留画出来的感觉。
- 主体：根据文章选一个具体动作或关系。调试设备、翻看笔记、整理资料、观察流程都可用；不要每张都重复男性人物坐在桌前。
- 氛围：自然暖光、安静专注、真实工程实践。人物是情境插画，不冒充作者真人或现场照片。
- 配色参考：纸白 `#F6F1E7`、深海军蓝 `#102B3F`、木色 `#C59A73`、青绿 `#477A77`、橙色点睛 `#D67E3F`。这是从参考图归纳的工作色板，并非要求逐像素匹配；橙色只用于少量强调。
- 字体：封面标题用清晰有力的深蓝中文无衬线粗体，正文标签用规整易读的中文。手写字只用于少量场景便签，不能影响关键信息识读。
- 标识：需要时用小号 Aiclaw；图中不强制塞博客域名或二维码。文章文末仍保留博客入口；小红书图集沿用原有不放二维码和外链的偏好。
- 画面不要自动追加励志标语、虚构终端输出或无关英文小字。屏幕、书脊和便签若有字，必须来自本次提供的文案。

## 不同类型的画法

### 封面

先用一组明显的标题与主题场景建立层次。横版可以标题与场景分区；竖版可以标题在上、场景在下。延续参考图的留白和标题分量，但不固定复制左右位置。保留裁切安全区，标题和主体不要贴边。

### 正文场景插画

用一个场景解释一个观点，例如“看完教程但知识仍散”“从回包核对结论”。可以没有大标题，避免每张插图都像另一张封面。沿用纸感、笔触、暖光和配色。

### 流程、原理与比较图

先确认关系、顺序与标签，再画图。使用同风格的小设备、笔记纸片、手绘容器与箭头；技术关系必须明确，不能为画面效果变动顺序或增加模块。每图聚焦一个问题，信息多时拆图。中文标签短而清楚。

数值图表、复杂架构图或密集代码优先采用确定性排版，保留本风格的背景、配色和少量手绘元素。不能为了全部手绘而牺牲准确性、文字可读性或连线清晰度。

### 多页知识图卡

同一组图片固定纸感、色板、笔触和标题层级，按内容变化构图；首图提出主题，后续每页讲清一个问题。平台适配时重排内容，不把横封面直接裁成竖图。

## 避免偏离

避免霓虹赛博、冷光机器人、油亮 3D、大片桃橙渐变、幼儿卡通、满屏贴纸、粗糙矢量拼贴或密集小字。也不要把当前文章那两张纯色流程卡当作本风格的主参考；用户认可的是封面插画。

## 成图检查

缩到实际手机展示尺寸，检查标题、关键标签和箭头仍能读清；确认没有错字或额外文案。与参考图并排看纸感、主色、画法和氛围是否相近，同时确认新图的内容适合当前文章。不同生图模型不能保证像素级一致，优先用同一基准图、明确文案与小幅定向修改来减少漂移。
