# 纸飞机与 Easel：定位、致谢与文章素材

本说明基于 2026-10-17 的纸飞机 0.1.75 源码及 [Easel 官方仓库](https://github.com/ZJU-REAL/Easel)介绍。Easel 的介绍属于其项目说明，不代表本文作者已逐项实测。

| 维度 | 纸飞机当前侧重 | Easel 官方介绍侧重 |
|---|---|---|
| 使用方式 | Windows 桌面与本地 Python Web 工作台；自选模型 API | OpenClaw Agent 与内容工作台协作 |
| 创作组织 | 个人文章母稿、提纲确认、候选正文采用、编辑旁修改 | 发现、策划、创作、发布、归因的连续 Agent 工作流 |
| 内容形态 | 长文、封面/正文插图、平台版本、已有视频素材引用 | 图文及丰富的音频、视频制作技能 |
| 交付管理 | 版本检查、草稿回执、结果未知先核对、公众号草稿准备 | 内容技能、媒体工具、多平台发布与运营分析协作 |
| 共同点 | 账号画像、素材、内容创作、平台适配与经验沉淀 | 同左；不是纸飞机独有能力 |

对希望在 Windows 上围绕一篇文章逐步修改、用自己模型 API、管理送稿状态的人，纸飞机提供了一条相对聚焦的路径。希望使用 OpenClaw Agent 调度更广泛的多媒体和社交内容技能的人，可以重点了解 Easel。两者有交集，应按实际任务、环境与平台权限选择，不能写成“谁全面替代谁”。

纸飞机感谢 Easel 提供的工作台理念与部分交互灵感，包括首次模型配置引导。未提供过对照实验，不应编造速度、质量、成本、成功率或用户规模排名。

## 可用于文章的真实内容

- 为什么做纸飞机：把自己的资料、账号习惯和文章反复修改流程组织起来，减少在多个任务和页面之间切换。
- 用一条具体流程讲产品：导入素材 → 选择画像 → 确认提纲 → 生成并采用正文 → 在编辑旁修改 → 准备图文 → 检查并送草稿 → 微信确认发表。
- 如实写改进中的问题：对话布局、选区过期、API 视频素材与图文视频的区别。0.1.75修正的是误报与通道使用，原生视频本地上传仍有人工作业。
- 明确项目是早期开源版本，功能存在平台差异；不要把目录中列出平台等同于全部真实验通。
- 项目地址：https://github.com/liuyuyan6100/paperplane ，MIT 许可证。公开状态以 GitHub 实际页面为准。
- 文末博客使用当前账号画像中已保存的真实地址；不能从源码编造私人联系方式。
