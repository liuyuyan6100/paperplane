# 数据与安全

源码版默认把业务数据写入项目 data/；可用 --data-dir 或 PAPERPLANE_DATA_DIR 指定独立目录。Windows 安装版默认使用 %LOCALAPPDATA%/PaperPlaneStudio/local。

数据目录包含文章、版本、对话、任务与回执数据库，以及图片、视频和单独保存的凭据配置。Windows 凭据使用当前系统用户的 DPAPI 加密，复制到其他电脑不代表可直接解密使用；其他系统使用文件权限保护，请自行保护磁盘和备份。

设置页的内容备份不包含 private.json 和密钥。恢复前停止对应实例并保留现有备份；恢复后核对文章和任务，不把历史队列直接当作待自动重发的指令。具体限制以当前恢复工具的校验和提示为准。

请勿提交 data/、private.json、Cookie、.env、数据库、业务备份、浏览器配置目录、平台真实回执或个人文章。报告问题时使用合成数据和脱敏日志。模型请求会把选用的创作上下文发给你配置的接口，先确认资料适合交给该服务。

本地服务默认只监听 127.0.0.1。需要远程访问时使用现有云端认证方案，不要直接将无认证的本地端口暴露到公网。

发现疑似凭据泄露时，先撤销或轮换对应凭据，再处理公开内容；仅从最新文件删除不能清除历史泄露。
