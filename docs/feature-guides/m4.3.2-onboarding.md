# M4.3.2 补齐：新手入门视觉模块

适用开发候选`0.4.0-m4.3.2-guide`；安装包`PaperPlaneStudioPreview-Setup-0.4.0.9.exe`；更新日期2026-10-21。用户要求引导是应用内独立模块与按钮，视觉直观展示流程，并在后续功能增改时同步更新。此前只有仓库中的文字页，不算实现该要求。

## 按步骤操作

| 编号 | 你来操作 | 应看到的结果 |
| --- | --- | --- |
| M4.3.2-G01 | 在新版编辑器左侧“新建文章”下方点“新手入门” | 独立弹窗展示“准备→选题→创作→成稿”四段流程，不遮挡为普通文档页 |
| M4.3.2-G02 | 点“选题”，再点“前往这一步” | 引导关闭，打开“帮我选题”；没有自动生成或创建文章 |
| M4.3.2-G03 | 重新打开引导，点“准备→建立账号画像→前往这一步” | 打开画像管理；没有自动保存画像 |
| M4.3.2-G04 | 在尚未保存文章时点“创作” | 显示先保存文章的提示，“前往这一步”禁用 |
| M4.3.2-G05 | 保存文章后，分别进入创作、配图、预览及任务中心 | 每个节点进入对应真实入口；引导本身不调用付费模型、不采用或发布 |
| M4.3.2-G06 | 将窗口缩到手机宽度，再点顶部“新手入门” | 四段流程改为两列，可滚动阅读；仍能关闭和重新打开，不横向溢出 |
