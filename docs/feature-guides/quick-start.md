# 新手入门：在应用里看创作流程

适用修订候选：`0.4.0-m4.4-drafts`，Windows安装版本`0.4.0.13`。新版编辑器左侧“新建文章”下方有独立的**“新手入门”**按钮；窄屏时入口出现在顶部工具栏。点击后打开可交互的流程图。

![新手入门四段流程](assets/m4.3.2-guide/flow.png)

上图拍摄于2026-10-21隔离浏览器和空白测试库，证明按钮、四段流程、步骤卡和入口提示的布局；不证明真实模型输出或用户安装验收。

## 四段路

**准备 → 选题 → 创作 → 成稿**。彩色“创作”是流程阶段，不是编辑器按钮。点它再选“素材、提纲与正文”，可看到实际入口“素材与创作”；点“前往这一步”打开该入口，已有待确认提纲时会回到原任务。模型配置会展开侧边AI，文章步骤回到标题区。没有已保存文章时，需要文章的后续步骤会禁用并说明原因。打开引导或跳转本身不会调用模型、采用内容或送稿。

第一次练习可在“帮我选题”中写“让读者验证Agent记忆的文章”，选定一个候选，核对新建的是空白选题文章，再补充可核实资料并保存。随后按流程审阅提纲、正文和图片，可先停在本机预览。要继续时，从“成稿 → 检查并衔接公众号草稿”进入新面板。查看只读；点“检查并送入公众号草稿箱”才启动，可能生成付费的摘要补齐建议。补齐保存后自动复查并继续送入草稿箱，建议先审阅再采用。已有回执或未知结果处理原任务，不重复送稿。

顶部与预览页均有独立入口；从检查问题跳转到文章信息、配图或公众号设置。等待阶段可停止；送入草稿后核对版本和回执。按[M4.4十步指导](m4.4-drafts.md)测试。当前M4.4待用户验收，M4.3.3已整体验收通过。
