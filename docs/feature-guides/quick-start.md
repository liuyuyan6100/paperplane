# 纸飞机入门：从想法到一篇图文

适用范围：Windows架构验证版 `0.4.0-m4.3.2`。这是按现有入口整理的首次操作路线；它不代表后续平台送稿或公开发表已经在新版编辑器完成。

## 先看整条路

1. **配置模型**：在“模型与生图设置”填入自己的兼容API地址、密钥及文字模型，并主动测试。只有点击生成类按钮才会发起模型请求，可能产生费用。
2. **建立画像**：在文章信息区打开“账号画像”，填写名称、内容方向、目标读者和运营目标并保存。画像是选题的上下文，其他长期资料仍按原入口管理。
3. **帮我选题**：点击“帮我选题”，选画像，写一段本次想法，明确点击“生成3个候选选题”。比较角度、读者收益和素材缺口，人工选定一项后才创建空白文章。逐项测试见[M4.3.2选题指南](m4.3.2-topics.md)。
4. **保存文章和素材**：检查标题，补入可核实的资料，先保存文章。打开“素材与创作”，选用文字或导入文件；原件不会因选用而修改。
5. **审提纲、审正文**：生成提纲后修改并确认，才生成待审正文。对照当前文章，主动采用并保存后才更新文章；查看[M4.1完整练习](m4.1-text-creation.md)。
6. **配图与预览**：生成或上传封面、正文图，审阅后采用；失败生成可从任务或配图记录查看，不占用已完成候选卡片。查看[M4.2配图指南](m4.2-images.md)。
7. **检查任务**：任务中心显示后台进度、待确认和失败记录。关闭任务中心不停止任务；“结果待核对”的送稿不能直接重发。当前任务列表尚无单条或批量收纳、回收站及自动超时分组。

## 第一次练习

用练习文章而非真实待发布稿操作：想法填“写一篇让读者验证Agent记忆的文章”，选择一份练习画像。选题生成后只选择一个候选；先确认新文章只是空白选题，再补两段自己能核实的材料并保存。熟悉提纲、正文和配图的审阅按钮后停止，不发起平台送稿。

**保存、采用、送入平台草稿、公开发表是四件事。** 当前新版编辑器主要覆盖图文创作；平台送稿等部分能力还在原工作台。发送到微信公众号草稿箱也不等于公开发表。
