# 新手入门：在应用里看创作流程

适用候选：`0.4.0-m4.3.2-guide`，Windows安装版本`0.4.0.9`。新版编辑器左侧“新建文章”下方有独立的**“新手入门”**按钮；窄屏时入口出现在顶部工具栏。点击后打开可交互的流程图，而不是要求使用者先阅读长文。

![新手入门四段流程](assets/m4.3.2-guide/flow.png)

上图拍摄于2026-10-21隔离浏览器和空白测试库，证明按钮、四段流程、步骤卡和入口提示的布局；不证明真实模型输出或用户安装验收。

## 四段路

**准备 → 选题 → 创作 → 成稿**。点彩色节点切换阶段，再点左侧步骤查看“入口”和“完成标志”；点“前往这一步”可打开对应的画像、选题、素材创作、配图、预览或任务中心。模型配置会展开侧边AI，文章步骤回到标题区。尚未保存文章时，需要文章的后续步骤会禁用并说明原因。打开引导或跳转本身不会调用模型、采用内容或送稿。

第一次练习可在“帮我选题”中写“让读者验证Agent记忆的文章”，选定一个候选，核对新建的是空白选题文章，再补充可核实资料并保存。随后按流程审阅提纲、正文和图片；停止在本机预览，不必送稿。生成可能产生模型费用，只有明确点击对应生成按钮才会发起请求。
