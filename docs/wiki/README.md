## 每轮更新什么

实现前写范围和预期；交付前补回归与安装包事实；安装后补运行核验；用户体验后补反馈、修复与确认。未知项保持未知，实际失败保留记录。这里是仓库内 Wiki；没有声称独立 GitHub Wiki 或其他云端知识库已同步。
