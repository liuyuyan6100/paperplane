# 使用指南：从素材到公众号草稿

需要照着操作并逐项核对结果时，打开[功能使用与验收指南](feature-guides/README.md)。架构验证版的[M4.1完整练习](feature-guides/m4.1-text-creation.md)包含示例素材、先保存文章的准备步骤、截图和验收记录。

首次使用建议从[从想法到图文的入门路线](feature-guides/quick-start.md)开始。

新版编辑器的P1.2选题开发候选可从“帮我选题”进入：选择一份已保存画像、写下本次想法，明确点击生成后比较三个候选；只有人工选定才创建空白选题文章。操作及未验收边界见[M4.3.2选题指南](feature-guides/m4.3.2-topics.md)。

本指南的本地数据流程使用合成数据回归。**真实模型生成质量、各平台账号权限、审核与公开发表没有在本次文档核验中实测**；下方外部服务步骤须由使用者以自己的账号核对。环境与逐项结果见 [核验表](VERIFICATION.md)。

## 1. 配置模型

打开「模型配置向导」，填写自己的兼容 API 地址、Key 和文字模型，保存后主动自测。本次仅验证配置保存、合成兼容接口和错误分支，未调用真实付费模型。生图模型可以单独配置；已有图片也能直接上传。不使用 AI 时可以手写文章。接口自测及生成可能消耗额度。

## 2. 建立画像与素材

在「画像管理」填写账号定位、目标读者、语气、署名与文末博客地址，选择本篇使用的画像。已确认经验与候选建议需区分，候选不会自动变成长期事实。

在「选题素材」记录主题和来源；可从共享资料库选择资料，也可导入自己的笔记。AI 使用视频时主要依赖你填写的内容说明，不代表它已经看过画面或核实全部事实。

## 3. 提纲、正文与编辑旁对话

开始创作后先检查提纲，修改并确认，再生成正文。审阅候选正文，点击采用后才更新原稿。

编辑器旁的 AI 对话可以讨论当前工作项或选中的段落。发送前核对处理方式、修改范围和选择内容；生成后先审阅，必要时查看对照再采用。文章在生成期间被修改时，按界面提示重新核对版本，避免直接覆盖。

## 4. 配图与视频

在配图工作台规划封面和正文图片；生成成功还需采用。真实操作截图请自行提供，AI 插图不能充当实测证据。

点击文章工具栏「+ 视频」导入小于 10 MiB 的 MP4，填写标题、内容说明，选择「插到开场」或「插到光标处」，保存后在预览中核对位置。当前的大小限制是纸飞机实现限制，不是微信所有上传方式的通用上限。

本次未重新实测微信账号的原生视频上传、转码和关联流程。公众号视频需在微信图文编辑器用「本地上传」上传成片并插入原文、保存，再回纸飞机选择「从微信草稿关联视频」。标注“API上传完成，可用于自定义菜单、自动回复等场景”的素材不能据此当作图文原生视频。配音、原创声明和审核结果需在微信核对，增加音轨不等于获得原创资格。

## 5. 检查并准备草稿

本节需要真实账号和平台接口权限，本次仅用合成回执验证防重复和恢复分支。配置公众号 AppID、AppSecret，测试对应权限与 IP 白名单。没有权限时可导出发布包后手动操作。

在文章页点击「检查并送入公众号草稿箱」。缺少摘要、作者或可恢复的配图信息时，查看准备建议并确认；需要人工补充的内容按提示处理。成功后在发布队列查看原草稿记录；出现“结果待核对”先核实是否已接收，不要重复发送。

## 6. 在微信确认发表

公开发表由使用者在微信后台完成，本次没有执行。进入微信后台预览同一篇草稿，检查文字、图片、视频声音和链接，再按微信提供的流程公开发表。纸飞机的“平台草稿”和使用引导完成标记都不代表已经公开发表。

其他平台请先查看渠道管理中的能力说明。保存发布记录、公开链接和真实数据，便于复盘；不要把生成建议当作真实运营数据。


## 架构验证版M3：任务中心

M1/M2已用户验收，M3候选在文章顶部提供“任务中心”，保留当前正文和AI输入，按原编号查看任务。失败恢复继续使用原输入快照；未知送稿先核对，不能直接重试。查看状态不会调用模型、保存正文或公开发表。安装与操作见[M3验收单](architecture/milestones/03-tasks-acceptance.md)，回归和当前边界见[M3实施记录](architecture/milestones/03-tasks-implementation.md)。本节描述架构验证分支，不表示稳定版已整体迁移。


## 架构验证版：文章信息与任务状态

在文章中展开“摘要、署名与更多信息”，保存一次并选定画像后，可点“AI补齐空白信息”。AI按当前正文生成摘要和标签；署名复用既有画像信息并展示来源，没有依据则留空。先核对建议，再确认填入空白字段，最后保存文章；已有手填内容、正文、封面和来源保留。生成期间改过文章时，按当前稿重新补齐。

“任务中心”用于查看AI处理进度、待你确认的建议以及失败/中断等异常。发送请求后自动留下记录，写作无需先创建任务，也不必一直打开。文章顶部“本篇”提示只看当前文章；它不自动采用或发表内容。具体安装验证见[当前M3验收单](architecture/milestones/03-tasks-acceptance.md)。

2026-10-22任务中心修订候选增加单条和批量归档、可恢复回收站与7天未变化筛选。图片候选失败从所属文章“封面与配图”检查原计划；任务中心不自动重试。操作见[任务收纳指南](feature-guides/m4.3.2-task-management.md)，真实安装验收待用户确认。


## 架构验证版M4.1：素材与创作

在新编辑器保存本篇文章后，点顶部“素材与创作”。勾选已有文章或素材，也可粘贴文字、导入UTF-8的Markdown/TXT/CSV文件，或从本机共享资料库导入文字资料。最多选用6份，原文件和共享资料不修改；输入内容作为资料，不作为模型执行指令。

填写要求后点“生成提纲”，可以关闭窗口继续编辑。提纲可修改、保存；明确点击“确认提纲并生成正文”才开始正文生成。正文先保留为待审稿，可编辑并保存本任务，原文章保持。查看当前文章与待审稿对照，点击“确认采用并保存文章”才写入文章新版本。生成期间原稿有修改时，先保存当前编辑，核对两份内容后选择保留当前稿、使用候选或手动合并。

重新生成可沿用已确认提纲；素材和要求有变化时，点“调整素材和要求”，新任务保留原提纲并要求重新确认。任务历史按原编号保存，中断与失败从任务中心恢复，不自动重放；原工作台入口继续保留。

架构验证版M4.1.2补齐[关闭习惯及文章管理](feature-guides/m4.1.2-desktop-and-library.md)：正常关闭首次选择会记住，可在顶部“设置”改动；左侧行“⋯”或右键提供归档及移入回收站，归档和回收站有独立查看、恢复入口。


2026-10-20最新验收：用户明确反馈“这次测试没问题了，M4.1验收通过”，M1–M4.1用户整体验收完成，包含本轮关闭习惯与文章管理补齐；未逐项反馈的特殊分支不补造人工实测。原失败、截图与修正记录保留。用户授权继续M4.2封面与正文配图，见[实施与交付](architecture/milestones/04-images-implementation.md)。M4其他单元和M5仍未整体完成。


2026-10-23新增：侧边栏“功能进度与规划”查看已完成、初步验收和待开发卡片、后续优先级。窄屏可从“新手入门 → 成稿 → 了解功能进度”进入；查看不会调用模型或修改草稿。入口随版本更新，见[操作与验收](feature-guides/m4.3.3-roadmap.md)。前一轮M4.3.2修订已获用户初步验收。

## 验证版：检查与公众号草稿

M4.4从顶部或图文预览进入“检查与公众号草稿”，先查看已保存版本和问题。主动启动后补齐并保存会自动复查，通过后送入草稿箱；补齐建议先审阅采用。完整[操作与测试指导](feature-guides/m4.4-drafts.md)，新手入门“成稿”可直接跳转。
